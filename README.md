# WP Social Login

Add Google OAuth sign-in to WordPress and WooCommerce.

## Installation and use

1. Place the `wp-social-login` folder in `wp-content/plugins/`.
2. Activate WP Social Login in the WordPress Plugins screen.

Open WP Social Login in the WordPress admin and enter the Google OAuth client ID and secret for your site.
